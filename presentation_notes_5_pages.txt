PAGE 1: PROJECT OVERVIEW & THE PROBLEM WE SOLVED
--------------------------------------------------------------------------------
1. PROJECT NAME:
   HackPulse — The Hackathon Engineering Blog & Live Builder Hub.

2. WHAT IS THIS WEBSITE?
   A modern, dark-themed platform where hackathon builders, developers, and teams 
   can document their 48-hour sprints, share technical postmortems, inspect system 
   architecture diagrams, and clone copy-ready starter code.

3. THE CORE PROBLEM IN HACKATHONS:
   - Over 85% of hackathon projects disappear into dead GitHub repositories after 
     judging is over.
   - Hackathon teams solve hard bugs and build amazing architectures under 48 hours, 
     but no one documents how they did it.
   - Judges only spend 180 seconds reviewing each project, so great code is often 
     lost without a strong story and clear presentation.

4. INSPIRATION FROM READYTOSCALE.IN:
   - We analyzed the website "readytoscale.in" (an e-commerce builder).
   - We took its modern visual look (dark obsidian colors, neon cyan & blue glows, 
     glassmorphism, and live synchronization) and translated it into a hackathon 
     developer blog.
   - Instead of syncing products and stores, HackPulse synchronizes hackathon sprint 
     logs with a live community reading feed.

PAGE 2: DESIGN SYSTEM & VISUAL ENGINEERING
--------------------------------------------------------------------------------
1. COLOR PALETTE:
   - Background: Deep Midnight Obsidian (#030712) — reduces eye strain and gives 
     a futuristic developer feel.
   - Primary Accents: Electric Blue (#2563eb), Electric Violet (#7c3aed), and 
     Neon Cyan (#06b6d4).
   - Card Backgrounds: Frosted translucent glass (rgba(255, 255, 255, 0.055)) 
     with 1px subtle white borders.

2. 8PX GEOMETRY:
   - Every card, button, search box, and modal window uses a strict 8-pixel border 
     radius. This gives the site a clean, modern, cohesive look matching 
     readytoscale.in.

3. SIGNATURE HERO ORBIT CARD:
   - On the right side of the main landing screen, there is an animated 3D card.
   - It features 4 orbiting chips rotating around a central hub:
     "Sprint" (building) -> "Article" (writing) -> "Demo" (pitching) -> "Podium" (winning).
   - It also has a sweeping light beam reflection and a live event feed simulating 
     real-time developer telemetry.

--------------------------------------------------------------------------------
PAGE 3: HOW THE SYSTEM WORKS (THE 3-TIER FLOW STAGE)
--------------------------------------------------------------------------------
The website features an interactive 3-step live pipeline in the "How It Works" 
section (#process):

STEP 1: THE AUTHOR STUDIO (CREATOR PANEL)
- Builders type their hackathon project title (e.g. "PulseGuard AI Reviewer"), 
  their sponsor track (e.g. "Google Gemini AI Track"), and their tech stack.
- They click "Publish Story To Feed".

STEP 2: THE KINETIC SYNC RAIL (DATA PIPELINE)
- A glowing vertical light line pulses downwards with 3 floating chips:
  "Build Log" -> "Architecture" -> "Live Demo".
- This visually shows how raw hackathon code is converted into a structured 
  article without any server delay.

STEP 3: THE READER PUBLICATION (COMMUNITY FEED)
- The reader preview card instantly updates with the new article title.
- A green popup toast appears: "New field note synced to feed".
- Readers can immediately click "Read Full Teardown" to see the full code and 
  architecture.

PAGE 4: PLATFORM FEATURES & INTERACTIVE CAPABILITIES
--------------------------------------------------------------------------------
1. 6 RICH WINNING FIELD NOTES:
   The website includes 6 complete technical articles with bespoke dark-mode artwork:
   - "Building PulseGuard: A Multi-Agent PR Reviewer in 36 Hours" (AI Agents)
   - "The 180-Second Stage Blueprint: Winning Over Tired Judges" (Pitch & Demo)
   - "Zero-Cold-Start Backends with Global Edge Workers" (Web3 & Infra)
   - "Unlocking Dual Sponsor Bounties Without Bloating UX" (Web3 & Infra)
   - "Surviving Hour 24: Scope Discipline for 4-Person Teams" (Team Ops)
   - "From 48-Hour Prototype to 1,200 Beta Users" (Startup Scale)

2. INSTANT SEARCH & CATEGORY FILTERING:
   - Users can filter articles by clicking category pills: "AI Agents", "Pitch & Demo", 
     "Web3 & Infra", "Team Ops", "Startup Scale", or "All Stories".
   - A live search bar instantly filters articles by keyword, title, tag, or author.

3. FULL ARTICLE READER MODAL WITH 1-CLICK CODE COPY:
   - Clicking any card opens a full-screen frosted glass reading window.
   - Includes real code blocks with a "Copy Code" button that copies snippets 
     directly to the clipboard.

4. LOCAL BOOKMARKING & IN-BROWSER POST COMPOSER:
   - Users can click the star icon on any card to save it to their "Saved" list 
     (saved in browser memory via localStorage).
   - Users can click "+ Write Field Note" to type their own post and immediately 
     see it appear in the feed.

PAGE 5: TECHNICAL STACK, HOSTING & LIVE DEMO LINKS
--------------------------------------------------------------------------------
1. TECHNOLOGY STACK:
   - Frontend: Pure Semantic HTML5, CSS3, and Vanilla JavaScript (ES6+).
   - Zero Framework Overhead: No React, Vue, or heavy libraries needed to run, 
     meaning the page loads in less than 200 milliseconds and works 100% offline.
   - Responsive Design: Smoothly adapts to desktop, tablet, and mobile screens 
     with a custom mobile navigation drawer.

2. CI/CD & DEPLOYMENT:
   - Hosted on: GitHub Pages with HTTPS encryption.
   - Automated Workflow: Whenever code is pushed to GitHub, a GitHub Actions 
     pipeline (.github/workflows/deploy.yml) automatically builds and publishes 
     the site in under 15 seconds.
