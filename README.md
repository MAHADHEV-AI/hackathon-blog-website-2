# HackPulse — Hackathon Engineering Blog & Playbooks

**HackPulse** is a modern dark-mesh hackathon blog, engineering teardown library, and interactive sprint playbook hub.

## Highlights

- **Dark Mesh Aesthetics**: Deep obsidian (`#030712`) background with layered electric blue (`#2563eb`), violet (`#7c3aed`), and cyan (`#06b6d4`) radial glows and frosted-glass cards.
- **Interactive Field Notes (`#blog`)**: 6 original hackathon teardowns with live category filtering, instant keyword search, `localStorage` bookmarking, a full-screen article reader modal, and 1-click code snippet copying.
- **Author Studio**: Built-in modal composer to draft and publish new hackathon blog posts directly into the live feed (`localStorage`-persisted).
- **Live Sync Flow (`#process`) & Showcase**: Animated 3-column author-to-reader pipeline, 5-step workflow cards, and bespoke visual artwork in `assets/`.
- **Zero-Build Static Deployment**: Pure HTML, CSS, and vanilla JavaScript—ready for GitHub Pages via `.github/workflows/deploy.yml`.
